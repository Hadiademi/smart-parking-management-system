    🚀 SI TA STARTOSH APLIKACIONIN - HAPI PAS HAPI
═══════════════════════════════════════════════════════════════

LEXO KËTË ME KUJDES DHE BËJ SAKTËSISHT SI SHKRUAN!

═══════════════════════════════════════════════════════════════
    HAPI 1: MBYLL GJITHÇKA
═══════════════════════════════════════════════════════════════

1. MBYLL të gjitha browser tabs
2. Në IntelliJ:
   - Nëse ka ndonjë aplikacion duke u ekzekutuar
   - Click butonin e kuq ⬛ STOP (lart djathtas)
3. PRIT 10 sekonda

═══════════════════════════════════════════════════════════════
    HAPI 2: RELOAD PROJEKT
═══════════════════════════════════════════════════════════════

Në IntelliJ:

1. File → Invalidate Caches
2. Click "Invalidate and Restart"
3. PRIT që IntelliJ të hapet sërish (1-2 minuta)
4. PRIT që Gradle të shkarkojë dependencies (2-3 minuta)
   - Shiko progress bar poshtë djathtas

═══════════════════════════════════════════════════════════════
    HAPI 3: CLEAN & BUILD
═══════════════════════════════════════════════════════════════

Në IntelliJ Terminal (poshtë), shkruaj:

gradlew clean build -x test

PRIT të përfundojë (30 sekonda)

═══════════════════════════════════════════════════════════════
    HAPI 4: RUN APLIKACIONIN
═══════════════════════════════════════════════════════════════

1. Në anën e majtë, gjej:
   src → main → java → com.example.demo → DemoApplication.java

2. DOUBLE-CLICK në DemoApplication.java

3. RIGHT-CLICK kudo në kod

4. Click: "Run 'DemoApplication.main()'"

5. PRIT 1 MINUTË (MOS NXITO!)

6. Shiko console poshtë - duhet të shohësh:

   🚀 Initializing Sample Data...
   ✅ Created 4 users
   ✅ Created 4 vehicles
   ✅ Created 3 parking lots
   ✅ Created 10 parking spots
   ✅ Created 2 subscriptions
   
   ✨ Sample Data Initialization Complete!
   
   Started DemoApplication in X.XXX seconds

═══════════════════════════════════════════════════════════════
    HAPI 5: TEST NË BROWSER
═══════════════════════════════════════════════════════════════

VETËM PAS QË TË SHOHËSH "Started DemoApplication"!

Hap Chrome/Firefox dhe shkruaj:

http://localhost:9090/api/users

DUHET TË SHOHËSH JSON ME 4 USERS!

   - File → Project Structure → SDK
